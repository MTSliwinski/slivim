# slivim

Personal Neovim configuration and related tooling.

## Contents

- `nvim/` — Standalone Neovim config (uses `lazy.nvim`), migrated from LunarVim.
  See `nvim/README.md` for install instructions and keymaps.
- `Dockerfile` — Builds a demo Ubuntu container with the `nvim/` config
  pre-installed, for trying the setup without touching your local machine.
- `run-demo.sh` — Builds and runs the demo Docker image interactively.

## Try it

```sh
./run-demo.sh
```
